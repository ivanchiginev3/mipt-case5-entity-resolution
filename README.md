# Система дедупликации и сопоставления сущностей ClearPic

Многоязычная система дедупликации и сопоставления сущностей для больших наборов корпоративных данных.

Проект реализует:
- многоязычную предобработку и транслитерацию;
- поиск дубликатов с использованием машинного обучения;
- масштабируемую стратегию блокировки;
- графовую кластеризацию;
- REST API для поиска и проверки дубликатов;
- запуск в Docker-контейнере.

---

# Описание проекта

Система предназначена для поиска и объединения записей, относящихся к одной и той же реальной сущности, в больших и шумных многоязычных наборах данных.

Основные возможности:
- поиск дубликатов;
- кластеризация записей;
- нечеткий поиск;
- дедупликация пакета записей;
- формирование канонических сущностей.

Итоговая система была протестирована на вручную размеченном тестовом наборе.

Финальные метрики:
- Precision: **0.973**
- Recall: **0.896**
- F1-score: **0.933**

---

# Данные

Полный алгоритм был применен к набору данных размером более:

- **3.65 млн записей**
- **1.71 млн уникальных сущностей**

Поддерживаются данные на:
- кириллице;
- латинице;
- армянском;
- монгольских транслитерациях;
- тюркских транслитерациях.

## REST API

Система предоставляет REST API на базе FastAPI.

Доступные endpoint’ы:

| Endpoint | Описание |
|---|---|
| `POST /search` | Поиск top-K похожих сущностей |
| `POST /check_duplicate` | Проверка, являются ли две записи дубликатами |
| `POST /deduplicate_batch` | Дедупликация пакета записей |

Swagger-документация:

```text
http://localhost:8000/docs
```

## Основные компоненты

### Предобработка

- детерминированная многоязычная транслитерация;
- нормализация;
- стандартизация юридических форм.

### Блокировка

Многоэтапная стратегия блокировки для масштабируемого поиска кандидатных пар.

### Модель сопоставления

`RandomForestClassifier` для оценки вероятности дубликата.

### Кластеризация

Графовая кластеризация с использованием `connected components / union-find`.

## Методология оценки

Итоговая система оценивалась на вручную размеченном многоязычном тестовом наборе.

Для оценки использовались:

- Precision;
- Recall;
- F1-score;
- confusion matrix;
- анализ ошибок.

Оценка проводилась для итоговой системы кластеризации, а не только для модели попарного сравнения.
